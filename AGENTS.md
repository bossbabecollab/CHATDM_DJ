## Homegrown Rules

- Make the smallest change that works. Prefer editing existing files over creating new ones.
- Never refactor, rename, or clean up code you didn't ask about.
- Never add dependencies, libraries, or files without asking first.
- Use the patterns, components, and styling already in this project.
- If a change grows beyond ~5 files or ~300 lines, stop, explain why, and ask before continuing.
- Write tests for every new feature or bug fix, and run the existing tests + typecheck before saying you're done. If tests fail, fix them — don't just report them.
- Commit messages: short — what changed, what you tested, what the current branch is. Never commit to main directly.
- Never post on, DM, connect to, or change anything on the @missdjbliss Instagram account.
- Never deploy anything or expose secret values in replies.
- No paid services or external APIs beyond what is already configured (no Zerion, etc.).
